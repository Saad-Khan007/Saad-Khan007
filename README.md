### 💫 About Me

👋 Hi there! I'm **Saad Bin Ayyaz**, a results-driven **Software Engineer & Full-Stack Developer** based in Lahore, Pakistan. I specialize in architecting scalable web applications, distributed backend microservices, real-time streaming architectures, and high-performance CMS/SEO solutions.

- 🔭 **Currently Building:** Enterprise-grade maritime surveillance and live video streaming microservices (**Quartermaster**).
- 💼 **Leading Engineering:** Development Team Lead overseeing custom full-stack enterprise ERP solutions built with Next.js, Node.js, and MS SQL Server.
- 🎮 **Creator of Game Bazaar:** Architected **[gamebazaar.io](https://gamebazaar.io)** — a Unity WebGL gaming marketplace and automated build publishing pipeline powered by Next.js 15, React 19, NestJS, and AWS CloudFront.
- ⚡ **Technical SEO & Multi-CMS Expert:** Engineered programmatic SEO, Core Web Vitals optimization (90+ PageSpeed), and custom templates across WordPress, Shopify, Duda, Webflow, and custom CMSs.
- ☁️ **Cloud & Real-Time:** Extensive hands-on experience with AWS (EC2, S3, CloudFront, Lambda, Kinesis Video Streams), WebSockets (Socket.IO with Redis), Docker, and PM2.
- 🎓 **Education:** Pursuing BS in Computer Science alongside full-time software engineering.
- 💬 **Ask Me About:** Full-Stack Architecture, Distributed Microservices, Live Video Streaming, Next.js/NestJS, and Technical SEO.
